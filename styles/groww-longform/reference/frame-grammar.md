# Groww long-form — frame-selection grammar

The decision rules an editor follows to assign one of the 8 frame types to each script line. Derived from a frame-by-frame audit of three published Groww long-form references (330 spans, 38.6 min pooled — see `reference-audit.md` in this folder for the full evidence):

- **A** — Bandhan vs Nippon Small Cap (head-to-head comparison, 13:45)
- **B** — Top 6 MF Types for Minimum Overlap (multi-category explainer, 11:42)
- **C** — Top 3 Arbitrage Funds Compared (concept + fund countdown, 13:08)

## The 8 frame types

| # | Type | One-line definition |
|---|---|---|
| 1 | Creator | Talking head on real wall; bare, or with a small serif text overlay / typewriter caption |
| 2 | Creator + data panel | Creator reframed left; lower-third or side panel carrying real data (table, timeline, callout) |
| 3 | Creator + text + illustration | Built mixed serif/sans text + complementing illustrations (rotating gold coins) on the creator shot |
| 4 | Text-only card | Lavender topic card (purple serif-italic + coins) or white legal page |
| 5 | Full-screen brand MG | Lavender-grid graphic: tables, pies, bars, fund circles, screener rows, concept scenes |
| 6 | MG + resolving text | Serif takeaway title lands on the running MG at the VO's conclusion clause; also recap card + endscreen |
| 7 | AI/CGI b-roll | Generated cutaway, black-box + grain treatment |
| 8 | Real-footage b-roll | Stock/filmed cutaway, same black-box + grain treatment |

## Cue → frame-type mapping (pooled evidence)

Counts are spans across A/B/C. "Consistency" = share of that cue's occurrences that got the stated type.

### 1. Naming a stat (a specific number is spoken)

**→ Type 5 full-screen data graphic** when the data is the payload (a table, pie, bar chart, screener row, dense calculation) — **37 spans (A×11, B×13, C×13)**. The exact cell/figure highlights (green chip/sweep) at the moment it is spoken; every such graphic carries a source line + "As on" date.
**→ Type 2 side/lower-third panel** when the creator stays on to narrate around a compact spec (2–6 rows: benchmarks, launch dates, AUM, expense ratios, turnover, cash %) — **14 spans (A×10, C×4)**.
**Consistency: ~51 of ~56 stat moments got a graphic (91%).** Deviations (stat spoken bare): A 403.6 (AUM + restrictions, 28 s), B 155.9 ("101–250 stocks", "5–10% overlap"), B 582.4 ($7B/$1B caps), C 300.68 (tax slabs — kept as creator+bullets), B 500.6 (headline as lower-third citation instead of MG).
Typical span: 3–10 s for a single figure; 12–20 s for a table walked cell-by-cell.
Worked examples — A 55.15 "कम से कम 65% स्माल कैप स्टॉक्स में" → full-screen 65% pie; B 513.8 "सिर्फ 25.3% का को-रिलेशन" → correlation matrix with the 25.3% cell flashing green; C 419.48 "direct expense ratio सिर्फ 0.26%" → lower-third expense table, rows highlight in VO order.

**Colour code (invariant):** green = good/quoted, red = worse, gold = mixed verdict; teal chips on indigo panels, green chips on white tables.

### 2. Fund comparison (two funds/plans/indices on the same metric)

**→ Type 5 mirrored tables/cards in identical layout, swapped in place** so numbers land in the same screen position — A×9 pairs (returns, StdDev, Sharpe, Beta, Sortino, capture ×2, twin expense panels), C×9 (each fund's returns/risk table vs the same benchmark columns), B×9 (screener tables, Value-vs-Contra feature walk, S&P-vs-Nifty). **Consistency: 3/3 videos, no exceptions.**
**→ Type 2 verdict scorecard** for the final multi-row verdict: A 701.7, a 12-row feature scorecard tinting green/red/gold row-by-row with VO — 85 s, the longest hold in any video.
Typical span: 8–17 s per table; the pair reads A-fund then B-fund back-to-back.
Worked examples — A 437.4→452.35 Nippon returns table then Bandhan's in the identical layout; B 453.5 "Value vs Contra" two-column table, cells highlight in sync for 20.8 s; C 449.24 Nippon-vs-benchmark trailing returns, fund cells then benchmark cells.

### 3. Opening a subtopic (new section / metric / fund announced)

**→ Type 4 lavender topic card, 1–4.3 s** — **25 cards (A×12, B×7, C×6)**. Trigger phrases: "अब बात करते हैं…", "अब चलिए देखते हैं…", "अगली कैटेगरी…", "नंबर थ्री से स्टार्ट करते हैं". Card length is cut to the spoken phrase (Sharpe card 1.9 s; Value card 1.1 s; section openers 2–4 s). Cards may morph titles in place to re-title a sub-section.
**→ Type 1 + inline serif mini-label + coins (1.3–2.6 s)** for minor sub-beats inside a block that don't earn a full card — C×9 ("Portfolio" / "Performance" / "Risk Adjusted…"), A×1 banner ("What are Arbitrage Funds?"-style in C at 47.48 too).
**Consistency: every single section/metric/fund announcement in all three videos got a card or an inline label — 35/35.**
Worked examples — A 77.35 "अब बात करते हैं एयूएम की" → "AUM" coin card; B 276.6 → "Flexi Cap Mutual Funds" card typing in; C 410.16 → "NUMBER 3 / Nippon India Arbitrage Fund" card.

### 4. Explanation (concept, mechanism, definition)

**→ Type 1 bare creator** is the default — **55 spans (A×15, B×23, C×17)**: definitions without data, bridges, rationales, interpretations after a table. Longest teaching holds run 12–52 s bare.
**→ Type 5 concept MG** when the concept has moving parts or numbers — 14 spans (B×11: venns, dot grids, crash pie, benchmark-hugging chart; C×3: the Reliance ₹2500/₹2550 worked example told in 3 MG acts).
**→ Type 2 sourced definition callout** when the definition has a citable source — A×3 (Sharpe, Beta, upside-capture formula: indigo panel, phrase-by-phrase highlight sweep, "Source:" line); C uses a full-screen karaoke-highlight card for the SEBI 65% rule (286.76) and an on-creator UTI definition box (138.0).
**Rule observed in A:** sourced definition → callout panel; unsourced definition (Sortino, downside-capture) → spoken bare to camera. 5/5 consistent.
Worked examples — A 520.55 Sharpe definition panel with sweep vs A 585.05 Sortino spoken bare; B 92.0 "benchmark hugging" → twin interleaved candle series; C 54.32–115.4 arbitrage mechanics as a 3-act worked-example MG.

### 5. Emphasis / pivot line ("लेकिन असली बात", "एक और इंटरेस्टिंग बात", "अब ध्यान दीजिए", "याद रखिए")

**→ Type 1, cut back to the creator's face** — 13 spans (A×4, B×6, C×3). The pivot to camera IS the emphasis device.
**→ Type 6 resolving title** when the emphasis is a conclusion the running MG can land: serif takeaway fades onto the graphic exactly on the conclusion clause — B×4 ("True Diversification", "Higher Portfolio Overlap", "Portfolio Protected…", "Goes into Same Type of Stocks"), A×1 (both betas "< 1" typographic resolve). Always in place, never on a cut.
**→ Type 3 / Type 4 flash** for question- or reveal-shaped emphasis: C 223.4 "suitable for all investors?" text+coins; C 260.56 "The biggest advantage?" 1.8 s card flash.
Worked examples — A 466.35 crash-zoom to creator for "सिर्फ रिटर्न्स देखकर जज करना काफी नहीं"; B 198.3 venn resolves to "True Diversification"; C 337.0 "Top 3 based on our research" reveal text.

### 6. Metaphor / mood / scenario (no data on screen)

**→ B-roll: type 8 if the image is filmable, type 7 if it is not** — **59 spans pooled (A: 7×5 + 8×15; B: 7×15 + 8×10; C: 7×9 + 8×5)**. Both types wear the identical 4-side black-box + grain treatment and are interchangeable at the edit level. Clips run **3–8 s, median ~5 s**. Market-mood conventions: red boards/crash loops = downturn/volatility; green boards/rising arrows = winners/value support (A pairs them back-to-back).
Real (8): drone sport, NYSE/SEBI facades, traders, desks, macro documents, watering can. AI (7): fantasy stadiums, holographic offices, wireframe bears, coin walls, neon skylines — images that can't be filmed.
Worked examples — A 285.5 "सीवियर मार्केट डाउनटर्न्स" → red crashing loop; B 12.6 "illusion of diversification" → AI man ringed by orbiting fund icons; C 2.72 "idle funds" → AI man on sofa with charts on every screen.

### 7. Hook / rhetorical question / agenda (line aimed at the viewer, first ~75 s)

**→ Type 3 creator + built text + coin illustrations** — 8 spans (A×1 FIFA hook, B×3 hook/question/agenda, C×2 agenda + question, +C reveal at 337). Mixed white-sans + purple-serif-italic text builds word-by-word as spoken. **Type 3 exists almost only in the intro block**; it never reappears later except a mid-video reveal.
Worked examples — B 3.0 "minimum overlap ke saath…?" text + flanking coins; A 2.32 FIFA question + football art; C 19.6 agenda questions typing on/off in sequence.

### 8. CTA (like/subscribe line)

**→ Subscribe unit overlaid on the continuous creator shot** (typed 2 or 3 by position) — 5 occurrences across 3/3 videos. White pill + cursor click → SUBSCRIBED + bell, 4.5–5.5 s, triggered on the spoken ask. Pattern: once in the intro block (~38–73 s) + once in the outro; C skips the intro one. The outro verbal-disclaimer + ask itself is type 1 bare (up to 31 s).

### 9. Story / journey (a person's career, a value growing over time)

**→ Type 2 journey timeline beside the creator** — A×4 (three fund-manager bios at 95.35/113.9/126.85, one node per spoken fact, 13–25 s each; AUM growth ₹10,000→₹25,000 Cr at 290.6). Only A has this content, so evidence is 1/3 videos but 4/4 within it. Second person reuses the identical slot via in-place reset.

### 10. Risk / warning / caveat

**→ Type 1, deliberately graphics-free, eye-to-camera** — C 152.2 ("लो रिस्क का मतलब जीरो रिस्क नहीं", 12.7 s bare), B 571.1 (RBI caveat), A's disclaimer beats. The absence of graphics is the treatment.
**→ Red-market b-roll** when the risk is a market event rather than advice — A×4 red loops, B 184.9 wireframe bear.

### 11. Listing criteria / reasons

**→ Type 5/6 build: one element per spoken item** — 6 spans (C 37.6 research-parameter pills + 348.96 six criteria boxes; A 268.9 star-bullet parameter list; B 40.5 piggy-row 3-line list; C 232.32/246.4 as creator-side checklists). Items pop exactly as named. 3/3 videos.

### 12. Verdict / takeaway (fund wrap-up, final judgment)

**→ Type 1 bare** for per-fund and final verdicts (C×6, incl. 28.4 s final takeaway) — opinion always returns to camera.
**→ Type 2 scorecard** for a structured multi-criteria verdict (A 85 s).
**→ Type 6 recap card** for a framework summary (B 595.6, 9.4 s).

### 13. Fixed slots (not decisions)

- **Opening legal card** (type 4, white): 1.5–3.0 s, silent, hard cut out as VO starts.
- **Endscreen** (type 6): exactly 10.0 s, hard cut after the spoken "bye bye", 20–26 s before file end.
- **Closing legal** (type 4): ~10 s static page under fast English VO, then (2 of 3 videos) a 5–6 s bottom-to-top crawl to the final frame.

## Ordered decision procedure

For each script line, take the FIRST rule that matches:

1. **Legal/compliance text** → type 4 white legal page (open card / close static / close crawl). Never lavender-styled.
2. **Sign-off complete** → endscreen (type 6), 10.0 s, then the closing legal chain.
3. **Like/subscribe ask** → subscribe unit overlaid on the running creator shot (no scene change).
4. **Announces a new section, metric or fund** ("अब बात करते हैं X…") → type 4 lavender topic card, 1–4 s cut to the phrase. Minor sub-beat inside a fund/metric block → type 1 + inline serif label + coins, 1.3–2.6 s.
5. **Question or promise aimed at the viewer** (hook, rhetorical question, agenda, reveal) → type 3 creator + built text + coins.
6. **Contains a specific number, or says "table/chart में देख सकते हैं"** → data graphic with the exact figure highlighted at the moment spoken + source line:
   - dense table / chart / pie / screener / calculation → **type 5 full-screen**;
   - compact spec (2–6 rows) the creator narrates around → **type 2 side panel**;
   - the same metric for the second fund → **identical mirrored layout, swap in place**.
7. **Compares two funds/plans/indices** → mirrored type-5 pair (or twin panels); verdict cells green/red/gold; a shared conclusion may resolve to type 6.
8. **Defines a term** → has a citable source: type 2 sourced callout with phrase-sweep; no source: type 1 bare.
9. **Person's history or a value evolving over time** → type 2 journey timeline, one node per fact.
10. **Lists criteria/reasons** → type 5/6 build, one element per item as named.
11. **Metaphor / mood / scenario, no data** → b-roll, 3–8 s: type 8 if filmable, type 7 if not; always black box + grain. Red = crash, green = rise.
12. **Warning/caveat aimed at the viewer** → type 1 bare, no graphics on purpose.
13. **Everything else** (bridges, interpretation, opinion, verdicts, rationale) → **type 1 bare creator**. When in doubt, cut back to her face.

## Pacing rules

- **Mean span 7.0 s pooled; medians 5.5–6.2 s per video.** Something on screen changes at least every ~10 s in normal flow.
- **Holds beyond ~20 s must be earned by a progressive build synced to VO** (cells lighting up, rows tinting, timeline growing): 85 s scorecard, 20.8 s feature table, 17–20 s returns tables. A static graphic never holds past ~10 s.
- **Bare-creator holds beyond ~15 s are deliberate teaching/trust passages** (28–53 s: methodology, definitions, final takeaway, outro disclaimer) — rare, max ~3 per video.
- **Topic cards are cut to the spoken phrase**: 1.0–4.3 s. Never pad them.
- **B-roll punctuates concept-heavy stretches every ~30–60 s** and thins out in data-heavy halves (A's back half has zero b-roll; C's countdown has exactly one breather per fund block). B-roll clips 3–8 s, never information carriers.
- **Alternation**: explainer format runs creator↔full-frame near 1:1 (B: 42%/58%). Never two full-frame graphics of different subjects back-to-back without either a creator beat or an in-place swap of the same layout.
- **Stat sync is frame-accurate**: the highlight lands on the cell as the number is spoken; list/criteria items pop as named; resolving titles land on the conclusion clause.
- **Intro block template** (all three): legal card → hook/question (3) → concept/metaphor tease (5/7/8) → agenda (3) → subscribe unit → \[optional logo sting] → first topic card, all inside ~75 s.
- **Structural loops observed**:
  - *Per-metric comparison loop* (A): [4 metric card] → [1 or 2 definition] → [5 fund-A table, cell lit] → [5 fund-B table, same layout] → optional [6 shared-verdict resolve].
  - *Per-fund countdown loop* (C): [4 fund card] → [1 beat] → [5 screener row] → [2 expense panel] → [1 "Portfolio" label] → [5 allocation] → [1 "Performance" label] → [5 returns vs benchmark] → [1/5 risk metrics] → [7/8 breather] → [1 verdict].
  - *Per-category explainer loop* (B): [4 category card] → [1 definition] → [5 concept MG] → [1/7/8 alternation] → [5 evidence table] → [5 "Top 3 (10Y)" table with AMFI source] → next card.

## The 5 strongest rules (by evidence)

1. **A spoken number gets a graphic with that exact figure highlighted at speak-time, plus a source line** — 51 of ~56 stat moments across 3/3 videos (91%); green=good / red=worse / gold=mixed.
2. **Every section/metric/fund announcement gets a lavender topic card (or inline serif label) cut to the phrase length** — 35/35 across 3/3 videos; cards 1.0–4.3 s.
3. **Interpretation, opinion and bridging always return to the bare creator** — 55+ explaining spans plus all verdict beats, 3/3 videos; warnings are deliberately graphics-free.
4. **No-data metaphor beats become black-boxed, grained b-roll: real footage if filmable, AI if not, 3–8 s** — 59 spans, 3/3 videos; never used to carry data.
5. **Same-metric fund comparisons use identical mirrored layouts swapped in place so numbers land in the same screen position, cells highlighting in VO order** — 27 comparison graphics (A×11, B×9, C×9... every instance in 3/3 videos), capped by the progressive verdict scorecard pattern.
